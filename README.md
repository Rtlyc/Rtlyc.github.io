# Academic Portfolio with Robots, Cats, and Games Theme

This is an academic portfolio project designed to showcase academic achievements, research interests, and experience with a playful theme incorporating elements of robots, cats, and games.

## Project Structure

The project consists of the following files and directories:

- **index.html**: The main home page featuring a profile image, name and position, and three sections (About Me, News, Research).
- **css/**: Contains stylesheets for the portfolio.
  - **main.css**: Main styles for layout, typography, and themed elements (robots, cats, games).
  - **responsive.css**: Styles for responsive design.
- **js/**: Contains JavaScript files for interactivity.
  - **main.js**: JavaScript code for dynamic features.
- **assets/**: Directory for assets such as fonts.
  - **fonts/**: Font files used in the portfolio.
- **pages/**: Contains individual HTML pages for different sections of the portfolio.
  - **research.html**: Details on research interests and projects.
  - **experience.html**: Overview of academic, teaching, and industry experience.
- **.gitignore**: Specifies files to be ignored by version control.

## Features

- A playful design incorporating elements of robots, cats, and games.
- Responsive layout that adapts to different screen sizes.
- Three main pages: Home, Research, and Experience.
- Thematic icons and design elements throughout the site.

## Theme Elements

- **Robots**: Represented by robot icons, frames, and technical design elements.
- **Cats**: Playful cat-themed icons and references to feline research.
- **Games**: Game controller icons and references to game AI and development.

## Setup Instructions

1. Clone the repository to your local machine.
2. Open `index.html` in a web browser to view the portfolio.
3. Replace placeholder content (text and images) with your own information.
4. Customize colors and theme elements in the CSS files if desired.

## Customization

- Replace the placeholder image in the home page with your own profile photo.
- Update text content with your personal information, achievements, and experience.
- Modify the color scheme by changing gradient values in the CSS.
- Add or remove sections based on your specific needs.
